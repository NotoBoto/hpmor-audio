# План развития Unison

## В работе (приложение 1.2 и сайт)
Всё настраивается и включается по желанию.
- Синхронизация прогресса между устройствами и сайтом (через приватный GitHub Gist).
- «Действующие лица»: персонажи книги, их голоса и образцы, подсветка реплик персонажа.
- Виджет на главный экран и плитка в шторке.
- Автоперемотка назад после долгой паузы.
- Чтение: поиск по главе и книге, настройки шрифта/интервалов/полей/фона/подсветки,
  подсветка предложения, долгое нажатие на слово (копировать, поделиться цитатой/картинкой, словарь),
  режим «только читать» с листанием.
- Плеер: своя скорость для каждой книги, таймер сна по расписанию, Chromecast, Android Auto.
- Книги без готовой озвучки: импорт EPUB/FB2/TXT и озвучка синтезатором телефона с подсветкой.
- Сайт: закладки, категории, статистика, действующие лица, поиск, синхронизация.
