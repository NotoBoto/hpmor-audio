# ГПиМРМ — аудиокнига с подсветкой текста

Неофициальная многоголосая озвучка русского перевода фанфика
«Гарри Поттер и методы рационального мышления» (Элиезер Юдковский), главы 1–122.
Веб-приложение: текст с подсветкой текущего слова, синхронизированный с аудио,
работает офлайн (кнопка «Скачать» у каждой главы).

## Лицензии и авторы
- Текст: Eliezer Yudkowsky, «Harry Potter and the Methods of Rationality»; русский перевод —
  коллектив переводчиков hpmor.ru. Распространяется по лицензии
  [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
  Эта озвучка — производная работа под той же лицензией, только некоммерческое использование.
- Синтез речи: [XTTS-v2](https://huggingface.co/coqui/XTTS-v2) (Coqui Public Model License,
  некоммерческое использование).
- Часть голосов клонирована по коротким фрагментам записей волонтёров
  [LibriVox](https://librivox.org/) (общественное достояние).
- Harry Potter принадлежит J. K. Rowling; проект не связан с правообладателями.
