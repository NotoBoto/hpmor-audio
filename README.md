## Что это

Unison — читалка-библиотека в духе Tachiyomi, только для книг. Каждого персонажа читает свой голос,
а на экране подсвечивается слово, которое звучит прямо сейчас. Можно слушать, читать или делать и то и другое.

- **Библиотека → книга → глава**: сетка обложек, страница книги с описанием и списком глав.
- **Синхронный текст**: подсветка текущего слова, реплики окрашены в цвет говорящего, нажмите на слово, чтобы перейти к нему.
- **Офлайн**: главы скачиваются на телефон (по одной, пачкой или все сразу) и работают без интернета.
- **Прогресс**: прослушанные главы, «Продолжить» с того же места, история, лента обновлений.
- **Обновления озвучки**: если главу переозвучили, скачанная копия помечается, и её можно обновить в один тап.
- **Для дороги**: экран не гаснет во время прослушивания, режим без интерфейса, управление из шторки и с гарнитуры.

## Приложение для Android

Нативное приложение в духе Tachiyomi/Mihon (Kotlin, Jetpack Compose, Media3):
фоновое воспроизведение со шторкой и экраном блокировки, мини-плеер, таймер сна (встряхните, чтобы продлить),
режим «текст» и режим «плеер», загрузки по Wi‑Fi, автозагрузка следующих глав, автоудаление прослушанных,
автообновление переозвученных глав, источники по ссылке, резервные копии, проверка обновлений.

**[Скачать APK](https://github.com/NotoBoto/unison/releases/latest)** · исходники — в папке [`android/`](android/).

## Книги с сайтов (расширения)

С версии 1.3.0 приложение берёт книги прямо с сайтов через расширения-источники: «Обзор» → «Сайты (расширения)».
Текст главы приходит с сайта, озвучивает её синтезатор телефона. Расширения ставятся только из репозиториев,
подписанных ключом Unison.

| Репозиторий | Источники | Как подключить |
|---|---|---|
| [unison-sources](https://github.com/NotoBoto/unison-sources) | Викитека | встроен в приложение |
| [unison-sources-extra](https://github.com/NotoBoto/unison-sources-extra) | RanobeLib, Author.Today | «Расширения» → «Добавить репозиторий» → `https://notoboto.github.io/unison-sources-extra/` |

Контент сайтов принадлежит их правообладателям: используйте его только для себя. Для глав 18+ на RanobeLib
и платных глав Author.Today нужен вход в свой аккаунт («Войти» на экране источника).

## Сайт на телефоне (без установки APK)

1. Откройте [notoboto.github.io/unison](https://notoboto.github.io/unison/) в Chrome.
2. Меню ⋮ → **Добавить на главный экран** (или «Установить приложение»).
3. В приложении откройте книгу и нажмите ⤓, чтобы скачать главы для офлайна.

## Как сделано

- Разметка ролей: каждая реплика текста размечена персонажем.
- Синтез речи: [XTTS-v2](https://huggingface.co/coqui/XTTS-v2), у каждой роли свой голос. Голоса — встроенные дикторы XTTS
  и клоны по коротким фрагментам записей [LibriVox](https://librivox.org/) (общественное достояние).
- Контроль качества: длительность каждой фразы проверяется, сбойные генерации пересоздаются,
  «хвосты» после последнего слова обрезаются по распознаванию речи.
- Синхронизация слов: [faster-whisper](https://github.com/SYSTRAN/faster-whisper) с пословными метками времени.
- Сайт: статический PWA без зависимостей и сборки (`index.html`, `app.js`, `sw.js`), аудио — Opus 32 кбит/с.
